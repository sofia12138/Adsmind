## 1. 02 账户组与命名规则

已通过：

- 账户组只接受当前应用广告账号；外应用账号和跨应用主键为安全 404。
- 同名创建为 409；命名模板未知占位符为 422；字段顺序、说明和预览持久化正确。
- viewer 列表可读、写入 403，页面显示只读提示。
- owner 在 App Two 浏览器创建账户组和命名规则，刷新后回读一致；菜单位于“广告资产库”且各出现一次。

未达到 L3：

- `app_account_groups` 与 `app_naming_rules` 没有 `revision` 字段。
- PUT 不接收 expected revision，两位编辑者会发生 last-write-wins，无法返回 409 防止丢失更新。
- 创建没有 request key；当前只有同名唯一约束和 409，不能证明请求幂等。

因此把并发与幂等缺口记为开放 P1，02 最高保持 L2。

## 2. 05 创意组

| 场景 | 实际结果 | 结果 |
| --- | --- | --- |
| 当前应用素材 | 只接受当前应用已选择素材；跨应用读取/创建为 404 | 通过 |
| latest | v1 uploaded 时可投放；新增 pending v2 后自动变为草稿阻断 | 通过 |
| pinned | 固定 v1 后新增 v2 仍保持 v1 且可投放 | 通过 |
| 未上传阻断 | pending 版本返回结构化阻断原因 | 通过 |
| 角色 | viewer 只读且无写入口，直接写为 403 | 通过 |
| 浏览器 | 页面同时显示 pinned“可投放”和 latest“草稿阻断”，刷新回读一致 | 通过 |

最终 DB 回读：tenant 2 / App One 有 1 个账户组、1 个命名规则和 2 个创意组。菜单与旧 URL 均保持可访问。
