## 1. 范围与边界

- 验证 JWT tenant claim、服务端忽略伪造 `X-Tenant-Id`、`X-Application-Id` 归属与状态、应用列表/详情、成员、账号、生命周期和用户级面板覆盖。
- 普通租户成员只能列出和查看明确分配的应用；owner/admin 可管理本租户全部应用。
- 未连接生产、共享数据库或外部平台；调度器注册与启动在临时 launcher 中替换为空操作，外部凭证为空。
