# AdsMind 最终导航架构

> 状态：已实施并完成本地隔离环境验收（2026-10-21）  
> 实施基线：`b7f0257f93fa07a342e9abad960c4a1b1d79a293`  
> 结构真值：`frontend/src/app/menu-config.ts`

## 1. 目标与边界

本次导航重构只调整入口顺序、分组归属和导航可见性。页面、原路由、接口、权限键、插件开关、内部入口约束、外部链接和服务端鉴权继续保留。导航隐藏不代表功能删除，也不构成新的授权边界。

最终结构包含 10 个一级入口或分组、49 个节点。一级直接入口为“首页概览”和“运营数据”，其余 8 项为分组。

## 3. 作用域与可见性

可见性按以下顺序收敛：

1. 登录与租户身份；
2. 当前应用及应用成员关系；
3. 角色默认面板和用户级权限覆盖；
4. `internalOnly`；
5. `pluginKey`；
6. 仅渲染仍有可见叶子的分组。

前端菜单继续以 `panelKey`、`pluginKey` 和 `internalOnly` 为显示条件。直接访问页面仍由 `AuthGuard` 和真实服务端接口分别校验，前端隐藏不会放宽服务端权限。

## 4. 路由兼容

- “账户组”保留 `/settings/account-groups` 和 `account_groups`。
- “命名规则”保留 `/settings/naming-rules` 和 `naming_rules`。
- 四个确认隐藏入口继续保留原路由和权限：`/ads/drafts`、`/ads/platform-preflight`、`/templates`、`/tiktok-materials`。
- 统一基线中后集成的 `/asset-analysis` 临时菜单入口不属于确认的 49 节点；本次只收敛导航入口，继续保留页面、`creatives` 权限和真实接口，可通过原 URL 访问。
- `/ads/create-tiktok-minis` 继续重定向到 `/ads/create`，完整保留 query string。
- “自动剪辑”的外部链接继续由 `VITE_CUTFLOW_URL`/本地开发回退值决定。

## 5. 侧栏交互规则

- 叶子选中态按精确路径计算；只有明确声明 `matchSubpaths` 的详情页面继承父叶子选中态。
- `/ads/create` 只选中“新建广告”，不同时选中“广告数据”。
- 路由进入某一分组时自动展开该分组，并把当前叶子滚动到可见区域。
- 分组按钮为原生 `button`，提供 `aria-expanded` 和 `aria-controls`，支持 Enter/Space。
- 侧栏与导航容器禁止横向滚动；长文案在 220px 侧栏内截断，纵向内容保持可滚动。

## 6. 明确不包含

- 不删除业务页面、路由、接口、权限键或数据。
- 不改变素材上传、素材/剧目分析及其他业务页面语义。
- 不改变服务端租户、应用或角色隔离。
- 不部署、不连接生产或真实广告平台，不执行平台写入。
